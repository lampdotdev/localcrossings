## Make Local Crossings yours

It's yours to change by asking Lamp. A few places to start:

- Give it a vintage atlas look
- Pin each answer on the map
- Make it about my favorite city

## Remix it with Lamp

[Lamp](https://lamp.dev) is a Mac app that builds apps from a description and changes them as you ask. In Lamp, choose File → Open from GitHub… and paste `https://github.com/lampdotdev/localcrossings`: you get this exact wish, yours to change, with the credits below kept.

## Build it yourself

With Apple's Command Line Tools installed (`xcode-select --install`):

```bash
./build.sh
```

The AI inside the app, and anything it does with other apps or devices, goes through Lamp, so those need Lamp open on the same Mac.
